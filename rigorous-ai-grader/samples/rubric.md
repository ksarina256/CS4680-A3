# Assignment 2: Python Basics. Grading Rubric (100 points)

## Task 1: Variables and Types (10 points)
Create one variable each of type int, float, str and bool, and print the type of each.
- Creates all four variables with the correct types (6 points)
- Prints the type of each variable using type() (4 points)

## Task 2: Loops (15 points)
Print the sum of all even numbers from 1 to 50.
- Uses a loop (for or while) (5 points)
- Prints the correct result, 650 (10 points)

## Task 3: Functions (15 points)
Write `is_palindrome(s)` that ignores letter case and spaces and returns True or False.
- Defines a function with the exact name `is_palindrome` and one parameter (5 points)
- Ignores letter case and spaces (5 points)
- Returns a bool and gives True for "Never odd or even" (5 points)

## Task 4: Lists and Dictionaries (15 points)
Given `words = ["apple", "banana", "cherry", "apple", "banana", "apple"]`, count how often each word occurs using a dictionary.
- Builds the counts in a dictionary (5 points)
- Correct counts: apple 3, banana 2, cherry 1 (10 points)

## Task 5: String Manipulation (15 points)
Given `s = "the quick brown fox"`, print it in title case and print the words in reverse order.
- Title case output is "The Quick Brown Fox" (7 points)
- Reversed word order output is "fox brown quick the" (8 points)

## Task 6: Recursion (15 points)
Write a recursive function `factorial(n)`.
- Has a correct base case (5 points)
- Has a correct recursive call (5 points)
- Shows factorial(5) equal to 120 (5 points)

## Task 7: Reflection (15 points)
Write 100 to 150 words about what was hardest in this assignment and how you worked through it.
- Names one specific difficulty (5 points)
- Describes the concrete steps taken to resolve it (5 points)
- Length is between 100 and 150 words (5 points)
